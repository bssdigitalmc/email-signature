# Email signature assets

Public image assets for the email signature of Ben Sylvester Strautmann, Counsellor to the Ambassador, Embassy of the Sovereign Order of Malta to the Principality of Monaco.

- `img/crossed-flags.png` (288×171): crossed flags of the Sovereign Order of Malta and the Principality of Monaco, shown at 96×57 in the signature.
- `img/crossed-flags-large.png` (529×314): larger version of the same image.
- `signature.html`: signature HTML for Spark (Settings → Signatures → HTML).

Keep this repository public and the file paths unchanged: sent emails load the image from these addresses.
